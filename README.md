# Controle de Níveis de Água

## Sobre o projeto

Este projeto foi desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas da ETEC.

O sistema simula o monitoramento de um reservatório de água, exibindo os níveis e identificando situações de alerta.

## Tecnologias utilizadas

- Python
- Biblioteca Colorama

## Níveis do reservatório

1. Nível 1 - Muito baixo (Crítico)
2. Nível 2 - Baixo
3. Nível 3 - Médio
4. Nível 4 - Alto
5. Nível 5 - Muito alto (Alerta)

## Funcionalidades

- Armazenamento dos níveis em uma lista.
- Função para definir cores conforme o nível.
- Exibição dos níveis no terminal.
- Simulação do nível atual do reservatório.

## Como executar

Instale a biblioteca Colorama:

```bash
py -m pip install colorama
```

Execute o programa:

```bash
py app.py
```
